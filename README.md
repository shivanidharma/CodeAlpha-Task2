# CodeAlpha-Task2
🎓 University FAQ Chatbot (Tkinter + NLP)
📌 Description

This is a desktop-based University FAQ Chatbot application built using Python's Tkinter GUI and Machine Learning (NLP) techniques. The chatbot answers common university-related questions such as admissions, scholarships, hostel, fees, programs, and exams.

It uses TF-IDF Vectorization and Cosine Similarity to understand user queries and find the most relevant answer from a predefined FAQ dataset.
🛠 Technologies Used
Python 
Tkinter (GUI)
scikit-learn (TF-IDF Vectorizer, Cosine Similarity)
NLP (Natural Language Processing)

Run the application
python Chatbot.py
